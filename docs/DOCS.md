# Discord in CLI 사용 설명서 📟

> 터미널(까만 화면)에서 디스코드 채팅을 읽고, 보내는 프로그램이에요!
> 이 문서는 **처음 해보는 사람도 따라할 수 있게** 아주 쉽게 설명했어요.
> (이 프로그램은 Rust로 다시 쓰여진 버전이에요 — 사용법은 예전 파이썬 버전과 같아요.)

---

## 1. 이게 뭐 하는 프로그램이에요? 🤔

보통 디스코드는 앱이나 웹사이트로 쓰잖아요?
이 프로그램은 그걸 **터미널(명령어 창)** 안에서 할 수 있게 해줘요.

이 프로그램이 할 수 있는 일:

- 📨 디스코드 채널에 올라오는 메시지를 터미널에서 실시간으로 보기
- ✍️ 터미널에서 타자 쳐서 메시지 보내기 (`@닉네임`은 자동으로 진짜 멘션으로 바뀌어요)
- 🔔 누가 나를 멘션(@나)하면 주황색으로 알려주기
- 🗑️ 누가 메시지를 **수정**하거나 **삭제**하면 그것도 보여주기
- 💾 오고 간 메시지를 파일로 저장하기 (기록 남기기)
- 🖼️ 사진이나 임베드(예쁜 카드 메시지)를 터미널에서 보기

> ⚠️ **중요:** 이건 디스코드 **봇(Bot)** 을 이용해서 동작해요.
> 그래서 먼저 "내 봇"을 하나 만들어야 해요. (걱정 마세요, 아래에서 설명해요!)

---

## 2. 준비물 🧰

시작하기 전에 컴퓨터에 이게 있어야 해요:

| 준비물 | 설명 |
|--------|------|
| **Rust** | 이 프로그램을 돌리는 언어예요. [rustup.rs](https://rustup.rs/)에서 설치해요 |
| **디스코드 계정** | 당연히 있어야겠죠? |
| **내 디스코드 서버** | 봇을 초대할 곳. 직접 만들어도 돼요 (무료) |

## 3. 디스코드 봇 만들기 🤖

> 이 부분이 제일 헷갈려요. 천천히 따라오세요!

### 3-1. 봇 만들기

1. [Discord Developer Portal](https://discord.com/developers/applications) 에 접속해요.
2. 오른쪽 위 **"New Application"** 버튼을 눌러요.
3. 이름을 아무거나 정하고 만들어요. (예: `내터미널봇`)
4. 왼쪽 메뉴에서 **"Bot"** 을 눌러요.
5. **"Reset Token"** 을 눌러서 나오는 긴 글자(토큰)를 **복사**해 둬요.
   - 🔑 이 토큰은 **비밀번호 같은 거예요!** 절대 남한테 보여주면 안 돼요.

### 3-2. 봇에게 권한 켜주기 (제일 중요! ⭐)

같은 **"Bot"** 화면을 아래로 내리면 **"Privileged Gateway Intents"** 가 있어요.
여기서 아래 **2개를 꼭 켜주세요** (안 켜면 메시지를 못 읽어요!):

- ✅ **MESSAGE CONTENT INTENT** (메시지 내용 읽기)
- ✅ **SERVER MEMBERS INTENT** (멤버 정보 읽기)

### 3-3. 봇을 내 서버에 초대하기

1. 왼쪽 메뉴 **"OAuth2"** → **"URL Generator"** 로 가요.
2. **SCOPES** 에서 `bot` 을 체크해요.
3. **BOT PERMISSIONS** 에서 `Read Messages/View Channels`, `Send Messages`, `Read Message History` 정도를 체크해요.
4. 맨 아래에 생긴 링크를 복사해서 브라우저 주소창에 붙여넣고, 내 서버를 골라 초대해요.

## 4. ID 알아내기 🔢 (서버 ID, 채널 ID)

프로그램한테 "어느 서버, 어느 채널을 볼지" 알려줘야 해요. 그게 ID예요.

1. 디스코드 앱에서 **설정 → 고급 → 개발자 모드** 를 켜요.
2. 서버 아이콘을 **마우스 오른쪽 클릭 → "서버 ID 복사"**
3. 채널 이름을 **마우스 오른쪽 클릭 → "채널 ID 복사"**

이 두 숫자를 잘 적어두세요!

---

## 5. 설치하기 💻

터미널을 열고 아래 명령어를 한 줄씩 입력하세요.

```bash
# 1. 프로젝트 폴더로 이동
cd discord_in_cli

# 2. 컴파일 (처음엔 좀 걸려요 ☕)
cargo build --release

# 3. 실행
./target/release/discord_in_cli
```

## 6. 설정 파일 만들기 ⚙️ (settings.json)

이 프로그램은 `settings.json` 이라는 파일을 보고 동작해요.
예시 파일인 **`settings.inc.json`** 을 복사해서 **`settings.json`** 으로 만들면 돼요.

```bash
cp settings.inc.json settings.json
```

그 다음 `settings.json` 을 열어서 내 정보로 바꿔주세요:

```json
{
    "SERVER_ID" : "여기에_서버_ID",
    "CHANNEL_ID" : "여기에_채널_ID",
    "TOKEN" : "여기에_봇_토큰",
    "ALLOW_MENTION_EVERYONE" : false,
    "SAVE_MESSAGES" : true,
    "SAVE_AS_JSON" : false,
    "SAVE_FILENAME" : "messages.log",
    "FETCH_HISTORY_LIMIT" : 10,
    "EMBED_VIEW_default" : false,
    "IMG_VIEW_default" : false,
    "USERNAME" : "Sparky",
    "WATCH_ID": [0, 1]
}
```

### 설정 하나하나 설명 📖

| 설정 이름 | 뜻 | 예시 |
|-----------|-----|------|
| `SERVER_ID` | 볼 서버의 ID | `"123456789"` |
| `CHANNEL_ID` | 기본으로 볼 채널의 ID | `"987654321"` |
| `TOKEN` | 3-1에서 복사한 봇 토큰 (🔑비밀!) | `"MTk4N..."` |
| `ALLOW_MENTION_EVERYONE` | `@everyone` 보내기 허용 여부 | `false` (막아둠) |
| `SAVE_MESSAGES` | 메시지를 파일로 저장할지 | `true` |
| `SAVE_AS_JSON` | 저장을 JSON 형식으로 할지 | `false` (그냥 글자로) |
| `SAVE_FILENAME` | 저장할 파일 이름 | `"messages.log"` |
| `FETCH_HISTORY_LIMIT` | 채널 들어갈 때 지난 메시지 몇 개 불러올지 | `10` |
| `EMBED_VIEW_default` | 시작할 때 임베드(카드)를 펼쳐서 볼지 | `false` |
| `IMG_VIEW_default` | 시작할 때 사진을 터미널에 그릴지 | `false` |
| `MSG_HISTORY_MAX` | `/edit`, `/reply`용 최근 메시지 보관 개수 | `50` |
| `USERNAME` | 내가 메시지 보낼 때 붙는 이름표 | `"Sparky"` |
| `WATCH_ID` | 멘션 알림을 받을 사용자 ID 목록 | `[123, 456]` |

> 🔒 `settings.json` 은 `.gitignore`에 들어있어서 깃에 안 올라가요. (토큰 보호!)

## 7. 실행하기 🚀

설정을 다 했으면 이제 켜봐요!

```bash
cargo build --release && ./target/release/discord_in_cli
```

성공하면 이런 게 나와요:

```
Logged in as: 내터미널봇
=== Server: '내 서버' (ID: ...) ===

📂 일반:
   💬  [Chat]  잡담 (ID: 987654321)
   🔊  [Voice] 음성방 (ID: ...)

Use '/select <channel_id>' to select a channel for monitoring and sending messages.
```

이제 봇이 볼 수 있는 채널 목록이 쭉 나와요! 👀

## 8. 사용법 — 명령어 모음 🎮

프로그램이 켜진 상태에서 터미널에 입력하는 명령어들이에요.
`/` 로 시작하는 건 **명령어**, 그냥 글자는 **보내는 메시지**예요.

| 입력 | 하는 일 |
|------|---------|
| `/select 채널ID` | 그 채널을 골라서 보기 시작 (지난 메시지도 불러옴) |
| `/exit` | 채널 선택을 풀고 다시 채널 목록 보기 |
| `/status` | 지금 어느 서버/채널에 연결됐는지 보기 |
| `/embed open` / `/embed close` | 임베드(카드 메시지) 펼쳐보기 켜기/끄기 |
| `/img open` / `/img close` | 사진을 터미널에 그려서 보기 켜기/끄기 |
| `/stop` | 봇 끄기 (안전하게 종료) |
| `/setrpc <텍스트> [online\|idle\|dnd\|offline]` | 봇 활동(RPC)과 상태 설정 |
| `/refresh` | 현재 선택 채널의 최근 메시지 새로고침 |
| `/messages` | 최근 메시지 목록에서 내가 보낸 메시지 보기 |
| `/messages all` | 최근 메시지 목록 전체 보기 |
| `/edit <새 내용>` | 가장 최근 내가 보낸 메시지 수정 |
| `/edit ~N <새 내용>` | 최근 메시지 기준 N번째 메시지 수정 |
| `/editmsg <메시지ID> <새 내용>` | 메시지 ID로 수정 |
| `/reply <내용>` | 가장 최근 메시지에 답글 전송 |
| `/reply ~N <내용>` | 최근 메시지 기준 N번째 메시지에 답글 전송 |
| `/uploadfile <파일경로>` | 로컬 파일 업로드 |
| `/downloadfile ~N [첨부번호] [저장경로]` | 최근 메시지 기준 첨부파일 다운로드 |
| `/downloadfile <메시지ID> [첨부번호] [저장경로]` | 메시지 ID 기준 첨부파일 다운로드 |
| `안녕하세요` | (`/` 없이) 그냥 치면 → 그 채널에 메시지 전송! |
| `@닉네임 안녕` | `@닉네임`은 자동으로 진짜 멘션으로 바뀌어서 전송돼요 |

### 메시지 관리 명령 한눈에 보기

```text
/messages
/messages all
/edit 안녕하세요 (최근 내 메시지 수정)
/edit ~3 수정할 내용
/reply 답글 내용
/reply ~2 특정 메시지로 답글
```

### 파일 다운로드 명령 자세히

```text
/downloadfile ~1
/downloadfile ~2 1
/downloadfile ~3 2 downloads
/downloadfile 123456789012345678 1 C:/tmp/file.png
```

- `첨부번호`를 생략하면 1번 첨부파일을 받습니다.
- `저장경로`를 생략하면 `downloads` 폴더가 자동 생성됩니다.
- 같은 이름 파일이 이미 있으면 `_1`, `_2`가 붙어서 저장됩니다.

### 사용 예시 흐름 🌟

```text
1. cargo build --release && ./target/release/discord_in_cli   ← 실행
2. /select 987654321    ← '잡담' 채널 고르기
3. (사람들 채팅이 실시간으로 보임)
4. 안녕 다들 뭐해?       ← 그냥 치면 메시지 전송됨
5. /img open            ← 사진도 터미널에서 보고 싶을 때
6. /downloadfile ~1     ← 최근 메시지 첨부파일 다운로드
7. /stop                ← 다 했으면 끄기
```

## 9. 화면에서 보이는 것들 설명 🎨

- **`[채널이름] 닉네임 (시간): 내용`** → 일반 메시지
- **보라색 닉네임** → 봇이 보낸 메시지예요
- **주황색 배경 메시지** → 나를 멘션했거나 `@everyone` 이 들어간 메시지 (알림!)
- **`Modified`** 가 붙은 줄 → 누가 메시지를 **수정**했어요 (`수정전 -> 수정후`)
- **`Deleted`** 가 붙은 줄 → 누가 메시지를 **삭제**했어요
- **`[Embed]` / `[Image]`** → 카드나 사진이 숨겨져 있다는 표시 (`/embed open`, `/img open` 으로 펼침)

## 10. 파일들이 무슨 일을 하나요? 🗂️

프로그램이 어떻게 만들어졌는지 궁금하다면!

```
discord_in_cli/
├── Cargo.toml            ← 📦 Rust 프로젝트 설정 & 라이브러리 목록
├── settings.json         ← ⚙️ 내 설정 (직접 만들어야 함)
├── settings.inc.json     ← 📋 설정 예시 파일 (복사해서 씀)
└── src/
    ├── main.rs           ← 🧠 프로그램 시작점 (여기서 다 시작됨)
    ├── config.rs         ← ⚙️ settings.json 읽기
    ├── state.rs          ← 🗃️ 공유 상태 (선택 채널, 메시지 버퍼, 보기 토글)
    ├── handler.rs        ← 📨 디스코드 이벤트 처리 (메시지/수정/삭제)
    ├── console.rs        ← ⌨️ 터미널 명령어 처리 루프
    ├── fmt.rs            ← 🎨 색깔 & 멘션 정리 & 메시지 출력
    ├── embed.rs          ← 🃏 임베드(카드)를 예쁘게 그리는 부분
    ├── image.rs          ← 🖼️ 사진을 터미널 그림으로 바꾸는 부분
    └── log.rs            ← 💾 메시지를 파일로 저장하는 부분
```

### 각 파일 한 줄 설명

- **`main.rs`**: 디스코드에 로그인하고, 설정을 읽고, 전체를 시작하는 중심 역할이에요.
- **`handler.rs`**: 새 메시지·수정·삭제 이벤트를 받아 화면에 출력하고 기록해요.
- **`console.rs`**: 내가 터미널에 입력한 `/명령어`를 처리하는 무한 루프예요.
- **`state.rs`**: 선택한 채널, 최근 메시지 버퍼, 임베드/이미지 보기 토글을 관리해요.
- **`fmt.rs`**: 터미널 색(보라/주황)과 `@멘션`을 예쁘게 다듬고 메시지를 그려요.
- **`embed.rs`**: 디스코드 임베드(제목·설명·버튼이 있는 카드)를 터미널 박스로 그려줘요.
- **`image.rs`**: 첨부된 사진을 다운받아서 터미널 글자/블록 그림으로 바꿔줘요.
- **`log.rs`**: 메시지가 오거나 수정/삭제되면 `messages.log` 파일에 기록해요.

## 11. 자주 생기는 문제 (오류 해결) 🩹

| 증상 | 원인 / 해결 |
|------|-------------|
| `Failed to read settings.json` | `settings.json` 파일을 안 만들었어요. 6번을 다시 보세요. |
| 메시지가 하나도 안 보여요 | 봇 권한(**MESSAGE CONTENT INTENT**)을 안 켰을 거예요. 3-2번 확인! |
| `SERVER_ID is not set` 오류 | `settings.json`의 `SERVER_ID`가 비었어요. 채워주세요. |
| 봇 이름은 떴는데 채널 목록이 안 나와요 | 봇을 서버에 초대 안 했거나, 그 채널을 볼 권한이 없어요. |
| 로그인 실패 / 토큰 오류 | `TOKEN`을 잘못 붙여넣었어요. 3-1에서 다시 복사하세요. |
| 사진(`/img open`)이 안 돼요 | 이미지 형식이 지원되지 않거나 다운로드 실패예요. PNG/JPEG/GIF/WebP를 확인하세요. |

## 12. 꼭 기억할 안전 수칙 🛡️

1. **봇 토큰은 절대 공유 금지!** (깃허브에 올리거나, 친구한테 보내면 안 돼요)
2. 토큰이 유출됐으면 Developer Portal에서 **"Reset Token"** 으로 새로 발급받으세요.
3. 봇은 초대된 서버에서만 동작해요. 남의 서버를 몰래 볼 수 없어요.
