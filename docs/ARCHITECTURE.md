# Discord in CLI 아키텍처 📐

> 프로그램이 **안에서 어떻게 돌아가는지** 알고 싶다면 이 문서를 보세요!
> **코드를 안 읽어도** 구조를 이해할 수 있게 쉽게 설명했어요.

---

## 1. 전체 구조 한눈에 보기 🗺️

이 프로그램은 **파일 5개**가 팀을 이뤄서 돌아가요.
`app.py`가 대장이고, `src/` 폴더 안의 4명이 부하예요.

```
discord_in_cli/
├── app.py                  ← 🧠 대장 (모든 걸 지휘하는 메인 파일)
└── src/
    ├── alert.py            ← 🔔 경비원 (멘션 감지)
    ├── embed_render.py     ← 🎨 화가 (임베드를 예쁘게 그림)
    ├── image_render.py     ← 🖼️ 사진사 (이미지를 글자로 변환)
    └── log.py              ← 📝 서기관 (메시지를 파일에 기록)
```

> 💡 `app.py`가 나머지 4개 파일을 전부 **불러다 쓰는** 구조예요.
> 부하 파일끼리는 서로 직접 말 안 해요. 무조건 대장을 통해서!

---

## 2. 누가 누구를 부르나요? (의존 관계) 🔗

화살표 방향은 "이 파일이 저 파일을 가져다 쓴다"는 뜻이에요.

```
                  ┌───────────────────────────┐
                  │         app.py            │
                  │         (대장 🧠)         │
                  └──┬──────┬──────┬──────┬───┘
                     │      │      │      │
          import     │      │      │      │  import
        ┌────────────┘      │      │      └────────────┐
        ▼                   ▼      ▼                   ▼
  ┌──────────┐     ┌────────────────────┐       ┌──────────┐
  │ alert.py │     │   embed_render.py  │       │  log.py  │
  │ 🔔경비원 │     │   🎨 화가          │       │ 📝서기관 │
  └──────────┘     └────────────────────┘       └──────────┘
                   ┌────────────────────┐
                   │  image_render.py   │
                   │   🖼️ 사진사        │
                   └────────────────────┘
```

| 파일 | 불러오는 것 (import) | 한 줄 설명 |
|------|---------------------|-----------|
| `app.py` | `alert`, `embed_render`, `image_render`, `log` | 4명 전부 불러서 씀 |
| `alert.py` | `discord`, `json` | 혼자 일해요 (외부 라이브러리만 씀) |
| `embed_render.py` | `discord`, `rich` | 혼자 일해요 |
| `image_render.py` | `discord`, `rich`, `climage`, `Pillow` | 혼자 일해요 |
| `log.py` | `discord`, `json`, `re` | 혼자 일해요 |

> 🔑 **핵심:** 부하 4명은 서로 모르는 사이예요!
> 전부 `app.py`한테만 보고하고, `app.py`만 얘네를 불러요.

## 3. 메시지가 왔을 때 일어나는 일 📨

누군가 디스코드에서 채팅을 치면, 이 순서대로 일이 벌어져요:

```
 디스코드 서버에서 메시지 발생! 💬
          │
          ▼
 ① app.py의 on_message()가 받아요
          │
          ▼
 ② "내가 보고 있는 채널의 메시지야?" 확인
          │
     ┌────┴────── 아니야 ──→ 무시! (끝)
     │
     ▼ 맞아!
 ③ alert.check(msg) 호출 ← 🔔 경비원한테 물어봄
     │
     ├─ "나를 멘션했어!" → 🟠 주황색 배경으로 표시
     └─ "아니야 그냥" → 평범하게 표시
          │
          ▼
 ④ log.log_message() 호출 ← 📝 서기관한테 기록 시킴
          │
          ▼
 ⑤ 임베드가 있고, embed_view가 켜져있으면?
     └─→ embed_render.render_embeds_and_components() ← 🎨 화가 호출
          │
          ▼
 ⑥ 이미지가 있고, img_view가 켜져있으면?
     └─→ image_render.render_images_async() ← 🖼️ 사진사 호출
          │
          ▼
 ⑦ 끝! 다음 메시지 기다리기 🔁
```

> ⚠️ 수정(`on_message_edit`)이나 삭제(`on_message_delete`)도 거의 같은 순서예요.
> 다만 화면에 `Modified` 나 `Deleted` 라고 다르게 표시해줘요.

## 4. app.py — 대장은 뭘 하나요? 🧠

`app.py`는 제일 큰 파일이에요. 크게 **3가지 역할**로 나눌 수 있어요.

### 4-1. 디스코드 이벤트 처리 (자동으로 작동)

디스코드에서 뭔가 일어나면 알아서 호출되는 함수들이에요.

| 함수 | 언제 호출? | 하는 일 |
|------|-----------|---------|
| `on_ready()` | 봇이 켜졌을 때 (딱 1번) | 채널 목록 보여주고, 콘솔 입력 대기 시작 |
| `on_message()` | 새 메시지가 올 때마다 | 화면에 표시 + 저장 |
| `on_message_edit()` | 메시지가 수정됐을 때 | "수정전 → 수정후" 보여주기 + 저장 |
| `on_message_delete()` | 메시지가 삭제됐을 때 | "삭제됨" 표시 + 저장 |

### 4-2. 콘솔 입력 처리 (`watch_console`)

터미널에서 내가 키보드로 치는 것을 계속 기다리는 무한 루프예요.

```
키보드 입력 기다림 ← 무한 루프!
      │
      ▼
  "/" 로 시작해? ──── 아니 ──→ 채팅 메시지로 전송!
      │
      ▼ 응, 명령어야
  어떤 명령어?
  ├─ /select    → 채널 전환
  ├─ /exit      → 채널 선택 해제
  ├─ /embed     → 임베드 보기 토글
  ├─ /img       → 이미지 보기 토글
  ├─ /status    → 현재 상태 확인
  ├─ /stop      → 봇 종료
  ├─ /setrpc    → 봇 활동 변경
  ├─ /refresh   → 봇 종료
  └─ 그 외      → "모르는 명령어" 에러
```

### 4-3. 메시지 출력 (`print_discord_msg`)

디스코드 메시지를 터미널에 **예쁘게** 보여주는 함수예요.

이 함수가 하는 판단:

```
1. 멘션된 메시지야?  → 주황색 배경!
2. 봇이 보낸 거야?   → 보라색 닉네임!
3. 수정된 메시지야?  → "Modified" 붙이기
4. 임베드 있어?      → embed_render 호출 (or 숨김 표시)
5. 이미지 있어?      → image_render 호출 (or 숨김 표시)
```

> 💡 `resolve_markup()` 이라는 함수도 있어요. 디스코드 커스텀 이모지 `<:이름:12345>` 를
> 터미널에서 읽기 좋게 `:이름:` 으로 바꿔줘요.

## 5. alert.py — 경비원 🔔

> "이 메시지에서 나를 불렀나?" 를 알려주는 파일이에요.

### 구조가 어떻게 되어있냐면

```
① 프로그램 시작 시
   settings.json에서 WATCH_ID 목록을 읽어요
   예: [12345, 67890]

② init(bot) — 봇이 켜질 때 1번 호출
   봇 자기 자신의 ID도 WATCH_ID 목록에 추가해요

③ check(msg) — 메시지 올 때마다 호출
   "이 메시지에 WATCH_ID 목록에 있는 사람이 멘션됐나?"
   → True(멘션됨!) / False(아님)
```

### check()가 True를 돌려주는 경우

| 상황 | 결과 |
|------|------|
| 메시지에 `@나` 가 있을 때 | ✅ True |
| 메시지에 `@everyone` 이 있을 때 | ✅ True |
| `WATCH_ID` 목록에 있는 ID가 멘션됐을 때 | ✅ True |
| 그 외 전부 | ❌ False |

## 6. embed_render.py — 화가 🎨

> 디스코드의 임베드(카드형 메시지)와 UI 컴포넌트를 터미널에 그려주는 파일이에요.

### 디스코드 임베드가 뭐냐면

봇이 보내는 **예쁜 카드 메시지** 있잖아요? 링크 미리보기 같은 것도요.
그걸 터미널에서 박스(`╭───╮`)로 바꿔서 보여줘요.

### 처리하는 요소들

| 임베드 요소 | 터미널에서 이렇게 보여요 |
|------------|----------------------|
| 👤 작성자(author) | 볼드 시안 색으로 표시 |
| 📌 제목(title) | 볼드 흰색으로 표시 |
| 📝 설명(description) | 일반 텍스트 |
| 🔹 필드(fields) | 3열 테이블로 가지런히 정렬 |
| 🖼️ 이미지/썸네일/비디오 | URL 링크로 표시 |
| 📅 푸터/타임스탬프 | 이탤릭 흐린 글씨 |

### UI 컴포넌트도 처리해요

| 컴포넌트 | 터미널에서 이렇게 보여요 |
|----------|----------------------|
| 🔘 버튼(Button) | `[ 버튼이름 ]` (시안색) |
| 📋 셀렉트 메뉴 | `▼ 선택하세요...` (마젠타색) |
| 💬 텍스트 디스플레이 | 흐린 흰색 텍스트 |
| ─ 구분선(Separator) | `────────────` 가로줄 |

> 💡 전부 [Rich](https://github.com/Textualize/rich) 라이브러리의 `Panel`, `Table`, `Text`를 써서 그려요.

## 7. image_render.py — 사진사 🖼️

> 이미지를 다운받아서 터미널에 **글자로** 그려주는 파일이에요. 제일 신기한 파일!

### 동작 순서

```
① 메시지에 이미지 첨부파일이 있으면 시작

② 디스코드에서 이미지 데이터를 다운로드

③ Pillow(PIL)로 이미지 열기 → RGBA로 변환

④ climage 라이브러리로 유니코드 블록 문자로 변환
   (이미지가 글자로 바뀌는 마법! ✨)

⑤ Rich의 Panel로 테두리 씌워서 터미널에 출력
```

### 실제로 이렇게 보여요

```
╭─ 🖼️ cat.png ──────────────╮
│ ▄▄▄▄▄▄▄                   │
│ ██▀▀▀██   ← 이런 식으로    │
│ ██   ██      글자로 이미지  │
│ ██▄▄▄██      나와요!       │
│ ▀▀▀▀▀▀▀                   │
╰────────────────────────────╯
```

> ⚠️ 이 기능을 쓰려면 `climage`와 `Pillow`가 설치되어 있어야 해요.

## 8. log.py — 서기관 📝

> 오고 간 메시지를 **파일로 저장**해서 나중에 볼 수 있게 하는 파일이에요.

### 두 가지 저장 모드

`settings.json`의 `SAVE_AS_JSON` 설정에 따라 저장 형식이 달라져요.

**📄 텍스트 모드** (`SAVE_AS_JSON: false`) — 사람이 읽기 편한 형식:

```
[2026-07-01 12:34:56] [서버 / 채널] 닉네임(ID): 안녕하세요~
[2026-07-01 12:35:00] [서버 / 채널] 닉네임(ID) 수정됨: 안녕 → 안녕하세요
[2026-07-01 12:35:30] [서버 / 채널] 닉네임(ID) Deleted: 안녕하세요
```

**📋 JSON 모드** (`SAVE_AS_JSON: true`) — 프로그램이 읽기 편한 형식:

```json
{
  "type": "message",
  "timestamp": "2026-07-01T12:34:56",
  "server": { "id": 123, "name": "서버" },
  "channel": { "id": 456, "name": "채널" },
  "author": { "id": 789, "name": "닉네임", "is_bot": false },
  "content": "안녕하세요~",
  "attachments": []
}
```

### 3가지 이벤트 전부 기록해요

| 이벤트 | 저장하는 정보 |
|--------|-------------|
| 새 메시지 | 작성자, 내용, 첨부파일 URL |
| 메시지 수정 | 수정 전 내용 + 수정 후 내용, 첨부파일 전/후 |
| 메시지 삭제 | 삭제된 메시지 내용, 첨부파일 |

> 💡 `SAVE_MESSAGES`를 `false`로 하면 저장 기능이 꺼져요.

## 9. 사용된 외부 라이브러리 📦

이 프로그램이 가져다 쓰는 남이 만든 도구들이에요.

| 라이브러리 | 어디서 쓰나 | 하는 일 |
|-----------|-----------|---------|
| `py-cord` (discord) | 전체 | 디스코드 API에 연결해서 메시지 주고받기 |
| `rich` | `app.py`, `embed_render.py`, `image_render.py` | 터미널에 색깔, 박스, 표 그리기 |
| `climage` | `image_render.py` | 이미지를 유니코드 글자로 변환 |
| `Pillow` (PIL) | `image_render.py` | 이미지 열고 처리하기 |

## 10. 전체 정리 — 한 장으로 보기 📋

```
┌─────────────────────────────────────────────────────┐
│                    Discord 서버                      │
│              (진짜 디스코드 서버)                    │
└──────────────┬──────────────────┬────────────────────┘
        메시지 수신 📨         메시지 발신 ✉️
               │                     ▲
               ▼                     │
┌──────────────────────────────────────────────────────┐
│                  app.py (대장 🧠)                    │
│                                                      │
│  on_message / on_edit / on_delete ← 이벤트 수신      │
│  watch_console                   ← 키보드 입력 처리  │
│  print_discord_msg               ← 화면 출력         │
│                                                      │
│  ┌─────────┬──────────────┬────────────────┐         │
│  │ 호출    │ 호출         │ 호출            │        │
│  ▼         ▼              ▼                ▼         │
│ alert   embed_render  image_render       log         │
│  🔔        🎨            🖼️              📝        │
│ 멘션?    임베드 그리기   이미지 그리기    파일 저장   │
└──────────────────────────────────────────────────────┘
               │
               ▼
        ┌──────────────┐
        │ messages.log │
        │ (저장된 기록) │
        └──────────────┘
```
